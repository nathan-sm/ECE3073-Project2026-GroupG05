This repository contains the complete hardware and software implementation for Milestone 1, featuring a Nios II system capable of real-time image processing and VGA display. To execute the project, users must compile the Quartus project to program the DE10-Lite FPGA and then build the Eclipse C project to initialize the processor. We have successfully integrated an SPI-controlled ESP-CAM for live video capture and an onboard accelerometer that triggers interrupts via double-taps. Additionally, the system includes a custom Verilog micro-second counter that provides accurate frame-rate benchmarking displayed directly on the board's HEX displays.
